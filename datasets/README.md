# Full Graph Data

These independently compressed JSON assets preserve the six current graph
projections across CIB, Iran and Vietnam, plus the original two CIB projections
needed for saved workbench guides. Manifest version 2 distinguishes the current
exploration release, the saved study release and any archived intermediate
releases. Exactly one exploration release per corpus is current. It records
both wire and decoded hashes, logical asset names, graph/hierarchy identities
and original source-asset hashes. Workstation locations in bootstrap metadata
are removed in separately hashed derivatives; source texts are not rewritten.

These are source-derived graph exports, not raw PDF archives, model-call logs,
private manuscripts, human-review comments or a benchmark answer-key file.
The full paired-release/classification views can expose later information.
They do not inherit a workbench question's strict historical cutoff or
whole-origin-document exclusion. The workbench's eligible quotations and the
independent map's broader context are different scopes.

Source texts were previously publicly distributed historical government
materials. Classification markings are retained. This repository does not
make a new declassification or blanket third-party licensing claim. See
`site/NOTICES.txt` for source provenance and rights notices.

The website loads individual files on demand from an immutable Git commit;
it does not download the entire dataset at startup. A full repository clone
includes approximately 2.93 GB of stored graph data, excluding Git history. The Pages application is packaged
separately in `site/`, below its own publication size guard.

The current CIB map uses source-sense-reviewed aliases and their rebuilt
hierarchy. Iran and Vietnam retain their earlier graph releases; they are not
claimed to have completed that newer source-only review. Saved guide routes
remain on their original immutable graph. New map data do not regrade or rerun
those saved suggestions. Identity authority is explicit where the export
records it and unknown for the legacy formats.
