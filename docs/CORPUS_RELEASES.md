## Active Source View

The current saved cases admit evidence dated on or before their source date.
CIB permits EARLIER/BOTH text from the originating document, never its later
release. Iran and Vietnam retain CONFIDENTIAL-only evidence, whole-origin
exclusion and document-wide handling vetoes. Historical strict-prior packets
remain strict-prior. Every native output, trace and guide carries its own bound
policy; a browser preference cannot silently change it.

not scored recoveries. Their historical reference remains unknown. Paragraph
window experiments and unfulfilled candidate-recovery goals are recorded as
such, not converted into benchmark accuracy. Later PDF originals are source
inspection material and do not become eligible evidence by being viewable.

Current guides carry current resource/registry/index pins and use the current
map. Only archived guides select the study revision. Unknown graph revisions
fail closed. Nodes are never remapped by names to make a saved route appear valid.

Dataset manifest version 2 inventories each logical asset under a declared
graph release. It allows current, saved-study, and archived exploration
releases, but exactly one current release per corpus. Both compressed and
decoded hashes are checked. Graph-identifying payloads must agree with every
referencing logical release, even when physical bytes are shared.

Legacy comparison/search exports have unknown identity authority. Their old
display labels cannot be upgraded into source-specific identities. Current
schemas require typed native `reference_scope` and
`instance_identity_asserted` fields on entity records. Navigation and source
co-occurrence remain distinct from identity and factual support.

## Reproducing A Resource Upgrade

The public adapter does not run extraction, aliasing, clustering, inference or
model assessment. Its input is an explicitly pinned, completed native resource
with matching alias/graph/hierarchy and publication receipts. It reads the
native files without editing them and never sends an API request.

1. Run `tools/refresh_cib_resource.py` with `--workspace`, `--resource` and the
   exact `--resource-sha256`. Preparation creates content-addressed datasets
   while keeping the active site's API index unchanged.
2. Run `tools/validate_publication.py --datasets-only` with the explicit dataset
   manifest hash. A fresh full scan is required after validation-policy or
   ancillary-notice changes. A failed or partial scan cannot issue a pass.
3. Commit and push the verified datasets. The publication adapter checks that
   the literal 40-hex data commit contains the exact prepared manifest. A data
   staging commit is not a completed website deployment.
4. Finish all UI edits, then run `tools/refresh_cib_resource.py --activate
   RESOURCE_ID --dataset-commit COMMIT`. Cooperating writers serialize through
   `.graph-refresh.lock`. Original preimages and every intended site/data
   dependency are pinned before installation; unknown edits cause a stop.
5. Run unit, managed-headless browser and full publication validation. Commit
   and push the resulting finite static site and code. Confirm the deployment
   outcome independently; a successful push is not proof of a Pages deploy.

Preparation and activation have immutable forward-resume plans. Repeating a
completed activation verifies site membership, all listed files, bulk data and
the committed inventory rather than silently resealing changes. Old private
research manifests and saved model receipts are not rewritten.

The older `prepare_graph_inputs.py` / `assemble_site.py` path starts from the
original saved-study registry. Do not blindly rerun it over a newer map and
erase the explicit current/study distinction. Coordinate through the release
contracts and keep different source bindings separately versioned.

## Publication Boundaries

The Pages artifact is `site/`; large graph datasets are fetched on demand from
one immutable Git commit. No API key or live inference proxy is permitted.
Only public historical source material and approved saved results are included.
This is not a new declassification or a blanket licensing decision.

Source-reviewed identity is a system decision, not independent historical
truth. More joins or agreement with a prior dictionary is not accuracy.
Retrospective identities/hierarchy also do not become historically constructed
knowledge merely because a query applies date and origin filters.
